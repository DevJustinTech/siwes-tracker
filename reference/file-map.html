File map & course plan

Every core PHP file in the project, what it's for, and which lesson dissects it. The course's table of contents and progress tracker in one place.

Scope: root .php files + partials/ + database.sql. The backend/ folder (Python) is out of scope — this app never calls it.

1The shape of the app

Plain PHP, no framework: every page is one file. A browser asks Apache for login.php; Apache hands the file to the PHP interpreter, which runs top-to-bottom, mixing "compute" (PHP lines) with "emit" (HTML lines), and sends the resulting HTML back. That's the whole architecture. Shared machinery lives in three files every page pulls in:

every page ──require──▶ helpers.php ──require──▶ config.php   (constants + session start)
                                   └─require──▶ partials/icons.php   (icon() function)

logged-in pages ──require──▶ partials/layout-top.php    …page HTML…  layout-bottom.php
