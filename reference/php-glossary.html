PHP glossary

Every language construct and function used in this project, with the file:line where you can see it in the wild.

Definitions per the PHP Manual · grow this as lessons cover more files

AThe basics you meet immediately

<?php … ?>
Open/close PHP tag. Everything between them is code the server runs; everything outside them is text (HTML) the server passes through to the browser untouched. Seen in: every file · Manual
<= … >
Short echo tag — prints an expression inline in HTML. <?= e($name) ?> means "run e($name), write its return value into the page here". login.php:38 · Manual: echo shorthand
$variable
Variables always start with $. Loosely typed — the same name can hold a string now, an array later. everywhere · Manual
'single' vs "double"
Single quotes: literal text. Double quotes: $vars inside get interpolated (replaced by their values). 'Location: ' . $path uses concatenation in helpers.php:35 · Manual
. and .=
The string join operator. 'a' . 'b' → "ab". helpers.php:16 (building the DSN), config.php:22 · Manual
require_once / require
Insert another file's code here and run it. require hard-fails if the file is missing; _once makes repeat requires no-ops (essential since many pages require helpers.php). Variables defined before the require stay visible inside the required file — that's how the layout partials know $page_title. login.php:2, layout-top.php:13 · Manual
__DIR__
Magic constant: the absolute path of the directory containing this file. Makes requires work no matter where PHP was started from. helpers.php:8 · Manual
function name(type $x): type
A function declaration with a typed parameter (string $value) and a typed return (: string / : void / : ?array). With declare(strict_types=1) active, types are enforced, not coerced. helpers.php:12, 27 · Manual
?
Two uses. (1) Nullable type: ?string = "a string or null" (e(?string $value)). (2) Ternary: $a ? $b : $c = if $a then $b else $c. helpers.php:27, dashboard.php:20
?? and ?: and ?->
$x ?? 'default': null-coalesce — use 'default' if $x is null/unset (no error). $a ?: $b: elvis — use $b if $a is falsy (empty, 0, ''). $str->method(): object call — you'll see it on PDO objects. ?? login.php:13 · ?: dashboard.php:125 · -> everywhere on $stmt · Manual
fn($x) => …
Arrow function — a one-expression inline function that auto-captures outer variables. register.php:9 ($old), dashboard.php:35 · Manual
foreach (… as $k => [$a, $b])
Loop over arrays; => gives key; square brackets destructure a nested array into named variables. layout-top.php:45 · Manual
array literals & keys
['a' => 1, 'b' => 2] is a map (string keys); [1, 2, 3] is a list. Access with $arr['key']. config.php:22–25 (cookie params), icons.php:9 (icon paths)

BThe web-runtime vocabulary

$_SERVER, $_GET, $_POST, $_SESSION
Superglobals — arrays PHP fills in for you, visible everywhere. $_SERVER['REQUEST_METHOD']: "GET or POST?" $_GET['id']: URL param. $_POST['email']: form field. $_SESSION: per-user server-side storage, persisted between requests via a cookie. login.php:10,13 · log_delete.php:6 · helpers.php:42 · Manual
header('Location: …')
Send a redirect instruction to the browser (HTTP 302). Only works before any output has been sent — which is why redirect() is always called at the top of a page, never after HTML. helpers.php:35 · Manual
exit
Stop running this file immediately. redirect() = send the header, then exit so no leftover code executes. helpers.php:36 (after redirect) and helpers.php:101 (CSRF expiry) · Manual
htmlspecialchars()
Replace < > & " ' with safe entities so user text can't become markup. The entire point of e(). helpers.php:29 · Manual
password_hash / password_verify
Turn a password into a salted bcrypt hash / check a candidate password against a stored hash — the hash can be checked but never reversed. register.php:43, login.php:23 · Manual
PDO
PHP's database driver class: connect once (new PDO($dsn, …)), query safely with placeholders (prepare() + execute([$vals])), fetch rows (fetch() = one row, fetchAll() = all rows, fetchColumn() = one value). helpers.php:12–24 · Manual
session_start / session_regenerate_id
session_start() resumes this visitor's server-side session (identified by an httponly cookie). session_regenerate_id(true) gives them a fresh session id after login so a pre-login id can't be hijacked. config.php:26, login.php:24 · Manual
hash_equals
Compare two strings without leaking timing information — the safe way to compare secrets like CSRF tokens. helpers.php:99 · Manual
